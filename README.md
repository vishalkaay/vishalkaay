## Vishal Raj

Final-year undergraduate at IIT Kanpur. I work on hardware security, GPU computing and command-line tools. Currently a security intern at C3iHub, building an IoT testbed for firmware and wireless auditing.

### Projects

- [**gifsleuth**](https://github.com/vishalkaay/gifsleuth). A zero-dependency forensics scanner for GIF files. It finds polyglots, web shells, appended archives and steganography in the regions a renderer never draws.
- [**histwise**](https://github.com/vishalkaay/histwise). A Go CLI that reads your bash, zsh or fish history and suggests the aliases that would save you the most keystrokes.
- [**aspen-mcp**](https://github.com/vishalkaay/aspen-mcp). An MCP server that lets Claude build, run and analyse Aspen Plus simulations in a live Aspen window.
- [**Pipelined AES-128**](https://github.com/CryptoPwners/Outer-round-pipelined-AES128). An 11-stage pipelined AES core in Verilog, verified against NIST vectors and deployed on a PYNQ-Z2.
- [**Fusion power prediction**](https://github.com/vishalkaay/Fusion-Power-Prediction-using-PINNs). A physics-informed neural network that predicts fusion reactor power output, compared against a standard network.
